# Interface



This project follows 3 SOLID principles:



1. **Single Responsibility Principle:** implemented when i split Ishape and ICreateShape so that each class had only one reason to change 



1. **Interface Segregation Principle:** implemented to avoid the use of dummy variables so that each side knows exactly what to do and accepting data fields they don't use



1. **Liskov Substitution Principle:** implemented to allow the interfaces to be used safely
